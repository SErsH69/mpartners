# M-PARTNERS — главная страница

Тема WordPress на базе `webula-wordpress-starter`. Главная свёрстана по макету
Figma [«(р) M-partners»](https://www.figma.com/design/X7Du0bfei1m9kZ4KFKojwf/-%D1%80--M-partners--Copy-)
в трёх разрешениях: **1920** (десктоп), **640** (планшет), **375** (мобилка).

## Шрифты

- **AA Stetica** (заголовки) — `assets/fonts/AAStetica-Regular.woff2/.woff`,
  сконвертирован из `AA Stetica Regular.otf` (в макете используется только
  начертание 400). Шрифт лицензионный, © Vasiliy Shishkin, поэтому в публичный
  репозиторий **не входит** (см. `.gitignore`). Положите файлы вручную:

  ```bash
  pip install fonttools brotli
  python3 -c "from fontTools.ttLib import TTFont as T;[ (f:=T('AA Stetica Regular.otf'), setattr(f,'flavor',x), f.save('assets/fonts/AAStetica-Regular.'+x)) for x in ('woff2','woff')]"
  ```

  Без него заголовки рисуются запасным Inter Tight и переносятся иначе.
- **ACF Pro** из стартера (`vendor-plugins/advanced-custom-fields-pro.zip`)
  тоже платный и в репозиторий не входит.
- **Inter Tight** (текст) — самохостинг, latin + cyrillic.

## Сборка

```bash
yarn install
yarn dev     # dev-сборка (чистит theme/dist и собирает заново)
yarn prod    # production-сборка
yarn watch   # пересборка на лету
```

Docker-окружение из стартера не изменилось:

```bash
cp sample.env .env
docker-compose up -d
```

## Анимации

- **Меню на ПК** (`assets/js/modules/dropdown.js`, `components/_nav-drop.scss`) —
  по мотивам flabbergast.agency: панель выезжает из полосы «Меню» той же
  ширины, фон под ней размыт (`backdrop-filter: blur(20px)`), пункты появляются
  лесенкой, бургер складывается в крестик. На планшете и мобилке остаётся
  полноэкранное меню.
- **Появление текста** (`assets/js/modules/reveal.js`, `components/_reveal.scss`) —
  по мотивам verteal.com: blur 14px → 0, сдвиг 22px, 0.9s,
  `cubic-bezier(.16, 1, .3, 1)`; строки заголовков появляются с шагом 0.14s.
  Первый экран и «Преимущества» анимируются при загрузке, остальное — при
  прокрутке. Учитывается `prefers-reduced-motion`.

## Просмотр на GitHub Pages

Pages отдаёт только статику, поэтому главная выгружается в готовый HTML:

```bash
yarn static   # сборка + php scripts/export-static.php → build-static/
```

GitHub Pages публикуется из ветки `main` (корень), поэтому готовая выгрузка
лежит в корне репозитория: `index.html`, `dist/`, `.nojekyll`. Чтобы обновить
сайт после правок:

```bash
yarn prod && php scripts/export-static.php --with-font
rm -rf dist index.html && cp -R build-static/dist build-static/index.html build-static/.nojekyll .
git add -A && git commit -m "Обновить выгрузку для Pages" && git push
```

Без `--with-font` лицензионный шрифт в выгрузку не попадает.

## Контент

Весь текст главной лежит в одном месте — `theme/inc/home-data.php`. Секции
читают его через `mp_data( 'hero.title' )`, поэтому подключить ACF/CPT можно
не трогая шаблоны:

```php
add_filter( 'mp_home_data', function ( $data ) {
    $data['hero']['title'] = get_field( 'hero_title', 'option' );
    return $data;
} );
```

Картинки берутся хелпером `mp_img( 'practice-1' )` → `theme/dist/img/figma/practice-1.png`
(файлы копирует webpack из `assets/img`).

## Форма связи

`POST` на `admin-ajax.php`, экшен `mp_contact` (`theme/inc/contact.php`):
проверяет nonce, имя, телефон и согласие, отправляет письмо через `wp_mail`.

- получатель — фильтр `mp_contact_recipient` (по умолчанию `admin_email`);
- после успешной отправки срабатывает экшен `mp_contact_submitted` — удобно
  повесить CRM или Telegram-уведомление.

## Адаптив

- **> 1024px** — десктопный макет, контейнер 1200px;
- **≤ 1024px** — планшетный макет (640): липкая компактная шапка, сетки в 2 колонки;
- **≤ 600px** — мобильный макет (375): одна колонка, уменьшенные отступы и кегли.

Горизонтальные ленты (отрасли, рекомендательные письма, команда) тянутся мышью
и свайпом — так они ведут себя в макете, где выходят за границы контейнера.

## Сверка с макетом

Вёрстка сверена с Figma попиксельно: рендер в headless Chrome на 1920 и 640
накладывался на экспорт секций из Figma, плюс замер боксов через DOM и сравнение
с координатами нод макета.

Что это дало (значения из Figma, а не «на глаз»):

- контейнер — 1200px контента (x 360…1560), а не 1200 вместе с полями;
- заливка «панелей» (карточки помощи, форма, офисы в подвале) имеет
  `opacity: 0.1` — без неё панели получались почти чёрными вместо бежевых;
- угол тёмного градиента считается от пропорций элемента, поэтому у секций,
  карточек и плашек он разный (102…139deg);
- логотипы партнёров в макете — маска, залитая `#342f2f`, а не сама картинка;
- иллюстрации кадрированы по `imageTransform` из Figma прямо в файлах, так что
  в CSS остаётся простой `object-fit`;
- иллюстрация третьей карточки «Помощь» в макете отражена по горизонтали;
- межсекционные отступы (100px) держатся в `margin`, чтобы не путаться с
  собственными паддингами секций.

Текущее расхождение по секциям на 1920: **1–11%** закрашенных пикселей
(первый экран — 1.1%); остаток почти целиком дизеринг растровых гравюр —
геометрия блоков совпадает с точностью до 1–2px, заголовки переносятся
так же, как в макете.

Фон первого экрана масштабируется вместе с шириной экрана: отступы узора
слева/справа — 195/194px при 1920, как в макете.

Мобилка (375) сверена так же: секция рендерится в iframe шириной 375
(headless Chrome на macOS не сужает окно меньше 500px). Все секции встают на
свои места с точностью ±1–5px, расхождение 3–16%. Что в мобильном и планшетном
макетах устроено иначе, чем на десктопе, и повторено в вёрстке:

- «Практика» — одна колонка, под каждой карточкой «Читать далее» + «+»;
- «Команда» — кнопка под лентой, под лентами «Отзывы» и «Команда» точки;
- «Специализация» — лента на мобилке открывается с середины;
- «География» — у городов свой порядок на планшете и мобилке;
- подвал — меню и услуги в две колонки, свой порядок юридических ссылок;
- в квизе ответы идут по колонкам: Уголовное, Банкротство | Гражданское, Административное.

Figma выводит строки 12/13.2 с шагом ровно 13px, поэтому на мобилке у мелкого
текста стоит `line-height: 13px` — иначе высоты блоков «плывут».

Отдельно: секции «Награды» нет в планшетном и мобильном макетах — на её месте
в макете пустое место (723px на планшете, 560px на мобилке). Секция оставлена
на всех разрешениях, чтобы не терять контент; из-за неё всё, что ниже, на
мобилке стоит на ~400px ниже, чем в макете.

## Что стоит знать

- `yarn lint` и `yarn lint:style` в стартере ссылаются на плагины
  `eslint-plugin-import` и `stylelint-use-logical-spec`, которых нет в
  `package.json`. Это досталось от стартера; чтобы линтеры заработали, их нужно
  доустановить.
- Картинки из Figma пережаты и обрезаны под фактические боксы макета
  (было ~35MB, стало ~8MB). Исходники в максимальном качестве при необходимости
  выгружаются из Figma заново.
- Блок `Spacer` из стартера сохранён без изменений.
